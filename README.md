# 🎵 Musicano Lite

Musicano Lite is a Telegram bot that allows you to search for songs, download them, and sync Spotify playlists directly to Telegram channels.

## 🚀 Features
- **Song Search:** Download music directly from Telegram.
- **Playlist Sync:** Mirror Spotify playlists to your Telegram channels.
- **Lightweight:** Optimized for free hosting platforms like Render.
